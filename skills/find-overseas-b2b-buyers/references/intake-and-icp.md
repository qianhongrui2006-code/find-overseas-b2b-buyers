# Intake and ICP

## First-use prompt

Offer three ways to begin: describe the business, upload existing materials, or provide the public company website. State that the user may write “不知道” and that only important missing information will be queried.

Ask for or extract:

| Priority | Field | Examples |
|---|---|---|
| Required | Product and scope | borosilicate double-wall glass; exclude laboratory glass |
| Required | Target geography | Germany and France; or ask AI to recommend |
| Required | Buyer types | importer, wholesaler, brand, hospitality supplier |
| Required | Target count | 10 calibration leads, then 50 |
| High | Cooperation model | OEM/ODM, private label, stock wholesale |
| High | MOQ and price position | MOQ 1,000; mid-market |
| High | Applications/channels | homeware, coffee, hotel/restaurant, gifts |
| High | Certifications | food-contact test, CE, FDA, FSC, etc. |
| High | Contact priority | procurement email, owner, corporate email, phone, WhatsApp |
| High | Exclusions | factories, marketplaces, tiny shops, existing CRM companies |
| Optional | Capacity and lead time | 100k/month; 30 days |
| Optional | Ideal customer examples | 3–10 company URLs |
| Optional | Competitors | brands, sellers, product URLs |
| Optional | Existing leads | for exclusion and lookalike analysis |

Do not infer HS codes as facts. Ask the user to confirm any HS code used with trade data.

## Document and website extraction

Extract only supported information. For every key attribute retain its origin: file and page/section, URL, user statement, or inference. Warn the user to remove bank data, contract secrets, bottom prices, credentials, and unrelated personal information before upload.

Website inspection should cover public Home, Product, Capability, About, Certification, Application, Download, and Contact pages. Treat marketing language as a claim, not independent proof.

## ICP structure

Create a compact profile with:

- supplier offering and differentiators;
- buyer problem/use case;
- priority buyer roles;
- target geography/language;
- channel and size fit;
- hard requirements;
- positive signals;
- exclusions;
- target contact roles;
- uncertainties and assumptions.

## Confirmation card

Before any prospect discovery, show a compact confirmation card. Do this even when the user's opening message already includes a website, files, a target country, and a requested number of leads.

Separate the card into:

### 1. Company understanding

- Main products and explicit exclusions.
- Business or cooperation model and differentiators.
- Known MOQ, capacity, certification, price-position, or delivery constraints.
- Important assumptions and unknowns, with their source labels.

### 2. Current screening target

1. Confirmed product scope.
2. Exact countries or regions for this run, plus search languages.
3. Priority buyer types with a one-line rationale.
4. Qualification and exclusion rules.
5. Planned sources and contact goals.
6. Calibration size and final target count.
7. Unknowns that may affect accuracy.

Never treat markets listed on the supplier's website, historical export markets, or “customers in 50 countries” as the geography for the current run. They are company-profile evidence only. If the user requests France and Germany for this run, exclude every other country until the user changes and reconfirms the brief.

End with one explicit question asking the user to confirm or correct the card. Do not search for prospects while awaiting the answer. A number such as “50 leads” states output quantity, not approval of AI-inferred countries or buyer types.

If the user provides only a website, end the profile with at most three high-impact questions. Offer a three-company exploratory sample if the user cannot answer.
