# 海外 B2B 买家发现与验证

`find-overseas-b2b-buyers` 是一个面向外贸工厂、出口企业和 B2B 销售团队的 Agent Skill。它帮助 AI 从企业介绍、产品资料或公司官网建立客户画像，确认本轮搜索范围，再通过公开网页和用户授权的数据来源发现、筛选并验证海外潜在客户。

## 主要能力

- 从文字说明、产品目录、企业资料或官网提取产品、优势、合作模式和限制条件。
- 在正式搜索前输出“公司理解”和“本轮筛选目标”，要求用户确认国家、客户类型、产品范围、数量及输出目录。
- 搜索进口商、分销商、批发商、品牌商、零售商、行业供应商等潜在买家。
- 综合企业官网、产品目录、地图商业资料、行业目录、展会与协会、官方社媒、新闻、招聘信息以及公开或授权的贸易数据。
- 以“存在合理采购链路”为核心判断客户相关性，避免把货代、报关行、相邻品类企业或仅被提及的公司误判为买家。
- 将邮箱或电话号码作为最终名单的硬性门槛：两者至少有一个公开且附有来源。
- 在内部完成去重、评分和证据检查，默认向业务人员输出精简、便于联系的 Excel 客户名单。

## 默认工作流程

1. 读取用户输入、上传资料或公开官网。
2. 生成公司理解和本轮客户筛选标准。
3. 强制确认目标地区、买家类型、数量和输出文件夹。
4. 建立候选公司池并进行快速初筛。
5. 验证产品关系、买家身份、市场位置、采购迹象和联系方式。
6. 排除缺少邮箱和电话、缺少采购链路或证据不足的公司。
7. 输出潜在客户、待人工复核、渠道证据和任务摘要。

## 安装

### 使用 GitHub Skill CLI

```powershell
gh skill install qianhongrui2006-code/find-overseas-b2b-buyers skills/find-overseas-b2b-buyers --agent codebuddy --scope user --force
```

如果目标平台不在安装器的代理列表中，可以下载适配平台的发布包，再按照该平台的本地 Skill 导入方式安装。

### 直接从 GitHub 下载

点击仓库页面的 **Code → Download ZIP** 可以下载整个源码仓库。用于直接安装时，请选择仓库中的：

```text
skills/find-overseas-b2b-buyers/
```

正式发布包可在仓库的 **Releases** 页面下载。不同平台可能对 ZIP 根目录和允许的文件类型有不同要求，因此应优先选择对应平台的发布包。

## 输出内容

默认业务表格优先展示：

- 公司名称
- 国家和城市
- 官网
- 业务邮箱
- 电话
- WhatsApp（仅在来源明确标注时）
- 联系方式来源
- 买家类型
- 匹配产品或采购链路
- 明确采购意愿及其日期和来源（如有）
- 推荐动作、简短理由和证据可信度

内部评分、Lead ID、查询词和去重字段默认不展示给业务人员，但可保留在结构化运行数据中用于审计和续跑。

## 使用边界

- 只使用公开可访问或用户明确授权的数据，不绕过登录、验证码、付费墙、访问限制或平台条款。
- 不把产品相关性自动等同于真实采购意愿。
- 不推测或伪造邮箱、电话、WhatsApp、采购记录和公司信息。
- 不保证达到指定客户数量；如果证据或联系方式不足，应如实报告缺口。
- Skill 负责发现和验证线索，不会在未经单独授权的情况下发送邮件、提交表单或联系客户。
